# LeetCode SQL Problems

This folder contains SQL solutions to selected LeetCode problems.
The problems are organized and solved as part of my SQL learning process.

Each solution focuses on:
- Understanding the problem statement
- Choosing the appropriate SQL constructs
- Writing clean and readable queries
- Explaining the reasoning using comments

## Concepts Practiced
- Aggregations and GROUP BY
- INNER and LEFT JOINs
- Subqueries
- Window functions (RANK, DENSE_RANK, ROW_NUMBER)
- Conditional logic using CASE

## File Naming Convention
Each file follows this format: <problem_number>_<problem_name>.sql

## Goal
To strengthen SQL fundamentals through consistent practice and revision.
